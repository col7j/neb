# استوديو ستوري (Story Studio)

لوحة تعديل ملفات الهوية لـ«ستوري العقارية»: الملف التعريفي، بطاقة العمل، عرض السعر، والعرض الفني والمالي — مع تصدير PDF.

نُسخت كما هي من الـ Artifact الأصلي على claude.ai (نسخة `1790620406-899f`).

## التشغيل محليًا

صفحة HTML ثابتة بدون أي build. تحتاج فقط سيرفر ملفات بسيط (بسبب الخطوط والصور):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## البنية

| المسار | الوصف |
|---|---|
| `index.html` | كل الواجهة والمنطق (HTML + CSS + JS) |
| `vendor/` | `html-to-image` و `jsPDF` لتصدير PDF |
| `fonts/` | خط ثمانية (Thmanyah Sans) |
| `img/` | الشعارات والصور المستخدمة في الشرائح |

## ملاحظات للنقل إلى منصة مستقلة

- **الحفظ:** الكود يستخدم قاعدة بيانات claude.ai (`claude.use('db')`) إذا كانت متاحة، وإلا يحفظ في `localStorage` للمتصفح فقط. خارج claude.ai سيعمل على `localStorage` تلقائيًا — لحفظ مشترك بين المستخدمين استبدل دوال `load` / `save` / `remove` في `index.html` بـ API خاص بك.
- **رفع الصور:** بدون `claude.use('assets')` تُضغط الصورة وتُحفظ كـ data URL. للإنتاج يُفضّل رفعها إلى تخزين (S3 أو ما شابه).
- **تنزيل PDF:** بدون `claude.use('downloads')` يُنزَّل الملف مباشرة عبر رابط `<a download>`.
- تأكد من ترخيص خط ثمانية والشعارات قبل النشر العام.
